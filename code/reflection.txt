I learned how different scraping techniques fit different pages: CSS selectors and
inner_text for menu cards, read_html and melt for tables, and waiting for
JavaScript and crawling linked pages for Canal Street. Fuzzy matching helped
normalize menu names, but scores alone were not reliable, so thresholds and a
human in the loop were important. In analysis, a merge indicator made it clear
which items were only ours, only rivals’, or shared.

I found asynchronous page updates and preserving the expected data shape most
challenging. I’ll practice by debugging Playwright selectors and testing small
pandas merges, especially their row order and missing values.
